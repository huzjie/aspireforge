# 术语表

| 术语 | 定义 |
| --- | --- |
| primitive | 原语，机器人最小可执行动作（move_to / grasp / place ...） |
| trajectory | 轨迹，一次执行的所有观测+动作序列 |
| root cause | 根因，失败归因的类别标签 |
| skill | 技能，验证过有效的控制代码 + 溯源 + 嵌入 |
| provenance | 溯源，技能的来源轨迹与验证结果 |
| distillation | 蒸馏，把成功程序抽象成可复用技能 |
| zero-shot | 零样本，未见任务不经训练直接求解 |
| memory hit | 记忆命中，检索到的技能已正确、直接成功 |
